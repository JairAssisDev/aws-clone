Domínio 2: Segurança e Conformidade (30%)

2.1 Modelo de Responsabilidade Compartilhada

Determina as fronteiras de segurança entre a AWS e o cliente.

  • Responsabilidade DA AWS ("Segurança DA Nuvem"):
    • Proteção física e segurança dos data centers.
    • Hardware e infraestrutura de rede física.
    • Software do hipervisor que executa a virtualização.
    • Manutenção dos serviços gerenciados (ex: Amazon S3, DynamoDB, RDS).
  • Responsabilidade DO CLIENTE ("Segurança NA Nuvem"):
    • Dados armazenados na AWS.
    • Gerenciamento de Identidade e Acesso (IAM) e senhas.
    • Configuração de Firewalls (Security Groups e Network ACLs).
    • Atualizações e patches do Sistema Operacional em instâncias EC2.
    • Criptografia de dados (In-Transit e At-Rest).

2.2 Gerenciamento de Identidade e Acesso (AWS IAM)

Serviço gratuito central para controlar quem tem acesso a quais recursos na conta AWS.

  • Conceitos Fundamentais:
    • Usuário Root: Conta criada no primeiro registro na AWS. Possui acesso irrestrito. Deve ser protegida com MFA e usada apenas para tarefas administrativas essenciais.
    • IAM Users (Usuários): Entidades criadas para representação de pessoas ou aplicações que interagem com a AWS.
    • IAM Groups (Grupos): Coleção de usuários para aplicar permissões idênticas de forma simplificada.
    • IAM Roles (Funções): Identidades com permissões temporárias assumidas por pessoas, aplicações ou serviços AWS (ex: permitir que um EC2 acesse o S3).
    • Políticas (Policies): Documentos JSON que definem o que é permitido (Allow) ou negado (Deny).
  • Princípio do Menor Privilégio (Least Privilege): Conceder apenas o nível mínimo de permissão necessário para a realização de uma tarefa específica.
  • MFA (Autenticação de Múltiplos Fatores): Camada adicional de segurança exigindo um segundo fator de autenticação para login.

2.3 Serviços de Segurança Integrados

  • AWS WAF (Web Application Firewall): Protege aplicações web contra exploits comuns da web e bots (proteção na Camada 7 - Aplicação).
  • AWS Shield: Proteção contra ataques de negação de serviço distribuída (DDoS). O nível Standard é gratuito para todos os recursos; o nível Advanced oferece proteção contra ataques complexos e mitigação personalizada.
  • AWS KMS (Key Management Service): Serviço gerenciado para criação e controle de chaves de criptografia usadas para proteger dados.
  • AWS Secrets Manager: Gerencia, rotaciona e recupera com segurança credenciais de banco de dados, chaves de API e outras chaves de acesso.
  • AWS Cognito: Fornece autenticação, autorização e gerenciamento de usuários para aplicações web e móveis.
  • AWS GuardDuty: Serviço de detecção de ameaças inteligente que monitora continuamente atividades maliciosas e comportamentos não autorizados na conta.
  • Amazon Inspector: Gerenciamento automatizado de vulnerabilidades que analisa cargas de trabalho (como instâncias EC2 e imagens de contêineres).

2.4 Conformidade e Auditoria

  • AWS Artifact: Portal centralizado sob demanda para download de documentos de conformidade (relatórios SOC, PCI-DSS, ISO) e contratos com a AWS.
  • AWS CloudTrail: Registra, monitora e retém o histórico de todas as chamadas de API feitas na conta AWS (quem fez o quê, quando e de onde).
  • AWS Config: Registra e avalia continuamente as configurações dos recursos da AWS para garantir conformidade com regras internas e políticas de governança.
