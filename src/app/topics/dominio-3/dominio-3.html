Domínio 3: Tecnologia e Serviços AWS (34%)

3.1 Infraestrutura Global da AWS

  • Regiões: Localizações geográficas físicas ao redor do mundo compostas por um agrupamento de Zonas de Disponibilidade isoladas.
  • Zonas de Disponibilidade (AZs): Um ou mais data centers distintos, com energia, resfriamento e segurança física independentes, conectados por rede de altíssima velocidade e baixíssima latência dentro de uma Região.
  • Localizações de Borda (Edge Locations / Points of Presence): Data centers menores espalhados pelo mundo usados por serviços como CloudFront e Route 53 para armazenar conteúdo em cache próximo aos usuários.

3.2 Serviços de Computação

  • Amazon EC2 (Elastic Compute Cloud): Servidores virtuais escaláveis e reconfiguráveis na nuvem.
  • AWS Lambda: Serviço de computação Serverless que executa código em resposta a eventos sem necessidade de provisionar ou gerenciar servidores.
  • AWS Elastic Beanstalk: Serviço de Plataforma como Serviço (PaaS) para rápida implantação e gerenciamento de aplicações web sem preocupação com a infraestrutura subjacente.
  • Containers AWS:
    • Amazon ECS (Elastic Container Service): Serviço de orquestração de contêineres Docker nativo da AWS.
    • Amazon EKS (Elastic Kubernetes Service): Serviço gerenciado de Kubernetes para executar e orquestrar contêineres.
    • AWS Fargate: Engine computacional Serverless para ECS e EKS, eliminando a gestão de nós/servidores virtuais.

3.3 Serviços de Armazenamento

  • Amazon S3 (Simple Storage Service): Armazenamento de objetos ilimitado, escalável e de altíssima durabilidade (99.999999999% / 11 noves).
    • Classes de Armazenamento: S3 Standard, S3 Intelligent-Tiering (otimização de custos automatizada), S3 Standard-IA (acesso infrequente), S3 One Zone-IA e S3 Glacier (arquivamento de longo prazo).
  • Amazon EBS (Elastic Block Store): Armazenamento em bloco de alto desempenho projetado para ser anexado a instâncias EC2 (funciona como um disco rígido virtual).
  • Amazon EFS (Elastic File System): Sistema de arquivos de rede (NFS) totalmente gerenciado, escalável e compartilhável simultaneamente entre centenas de instâncias EC2.
  • AWS Storage Gateway: Serviço híbrido que conecta ambientes locais (on-premises) ao armazenamento na nuvem AWS.

3.4 Serviços de Bancos de Dados

  • Amazon RDS (Relational Database Service): Banco de dados relacional gerenciado que suporta mecanismos como MySQL, PostgreSQL, MariaDB, Oracle e SQL Server.
  • Amazon Aurora: Banco de dados relacional de alto desempenho construído para a nuvem pela AWS, totalmente compatível com MySQL e PostgreSQL.
  • Amazon DynamoDB: Banco de dados NoSQL do tipo chave-valor totalmente gerenciado, sem servidor (Serverless), com latência na casa dos milissegundos.
  • Amazon Redshift: Serviço de Data Warehouse em escala petabyte para análise avançada de dados (Business Intelligence).
  • Amazon ElastiCache: Serviço de cache em memória (Redis ou Memcached) para aceleração de leitura de aplicações.

3.5 Redes e Entrega de Conteúdo

  • Amazon VPC (Virtual Private Cloud): Rede virtual isolada e dedicada à sua conta na AWS.
    • Subnets (Sub-redes): Divisões de uma VPC. Podem ser Públicas (com acesso direto à internet) ou Privadas (sem acesso direto externo).
    • Internet Gateway (IGW): Componente de VPC que permite comunicação entre instâncias da sub-rede pública e a internet.
    • Security Groups: Firewall virtual de nível de instância (com estado / stateful).
    • Network ACLs (NACL): Firewall virtual de nível de sub-rede (sem estado / stateless).
  • Amazon Route 53: Serviço de DNS (Domain Name System) altamente disponível e escalável, e gerenciador de domínios.
  • Amazon CloudFront: Rede de Entrega de Conteúdo (CDN) global que acelera a distribuição de arquivos estáticos e dinâmicos aproximando o conteúdo do usuário final.
  • AWS Direct Connect: Estabelece uma conexão de rede dedicada e privada entre o data center físico do cliente e a AWS, evitando a internet pública.

3.6 Integração e Ferramentas Adicionais

  • Amazon SQS (Simple Queue Service): Serviço de filas de mensagens gerenciado para desacoplamento de microsserviços.
  • Amazon SNS (Simple Notification Service): Serviço de publicação/assinatura (Pub/Sub) para envio de notificações por SMS, e-mail e push.
  • AWS EventBridge: Barramento de eventos Serverless para conectar aplicações usando dados de suas próprias aplicações ou serviços AWS.
  • Amazon Athena: Serviço de consulta interativa que permite analisar dados armazenados no Amazon S3 diretamente usando SQL padrão.
