2. Na migração: mover

Serviço Move o quê
AWS Application Migration Service Servidores inteiros para EC2 (rehost / lift-and-shift).
AWS Database Migration Service (DMS) Bancos de dados, com o banco de origem funcionando durante a migração.
AWS DataSync Arquivos, pela rede.
AWS Snowball Edge Grandes volumes de dados, fisicamente, quando falta rede.
TESTE RÁPIDO

Custo → Pricing Calculator / Migration Evaluator. Inventário → Application Discovery. Servidor → Application Migration Service. Banco → DMS.

Uma empresa quer coletar dados de uso e configuração dos servidores do seu data center para planejar a migração. Qual serviço?
A) AWS DMS · B) AWS Application Discovery Service · C) AWS Pricing Calculator · D) AWS DataSync
B — Application Discovery Service. Faz o inventário dos servidores locais.
Uma empresa quer estimar o TCO de migrar seus servidores para a AWS. Quais ferramentas? (Escolha duas.)
A) AWS Pricing Calculator · B) AWS Cost Explorer · C) Migration Evaluator · D) AWS Budgets · E) AWS DMS
A e C. Cost Explorer e Budgets só funcionam com gastos que já existem na AWS.
