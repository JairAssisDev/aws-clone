9. Elastic Load Balancing, CodeDeploy e armazenamento SMB

Elastic Load Balancing

DISTRIBUIR TRÁFEGO

Distribui o tráfego entre vários recursos de computação (instâncias, contêineres, IPs). Quem escala as instâncias é o Auto Scaling, não o ELB.

AWS CodeDeploy

IMPLANTAR

Automatiza a implantação de software em EC2, servidores on-premises, Lambda e ECS. CodePipeline orquestra o fluxo; CodeBuild compila e testa.

Amazon FSx for Windows File Server

SMB / WINDOWS

Sistema de arquivos gerenciado acessível via SMB. EFS usa NFS (Linux); EBS é disco em blocos de uma instância; S3 é armazenamento de objetos.

Uma empresa quer automatizar a implantação de uma nova versão da aplicação em 20 servidores no próprio data center e em 10 instâncias EC2. Qual serviço?
A) AWS CodeCommit · B) AWS CodeBuild · C) AWS CodeDeploy · D) AWS CodeArtifact
C — CodeDeploy. Implanta tanto em EC2 quanto em servidores on-premises.
Servidores Linux precisam compartilhar os mesmos arquivos ao mesmo tempo, usando NFS. E se fossem servidores Windows usando SMB?
Linux/NFS → Amazon EFS. Windows/SMB → Amazon FSx for Windows File Server.
